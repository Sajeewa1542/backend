TERMINAL 1 - BACKEND:
────────────────────
1. Navigate to project:
   cd c:\Chatbot\Wickramasingha\ SP\Hybrid-Chatbot-for-Evaluation-of-Variation-Proposals

2. Install dependencies:
   pip install -r backend/requirements.txt

3. Configure API key (create/edit backend/.env):
   GROQ_API_KEY=your_api_key_here

4. Start backend:
   python -m backend.main

   ✅ Wait for: "Application startup complete"
   ✅ Backend URL: http://localhost:8000

─────────────────────

   VITE_API_BASE_URL=http://localhost:8000

4. Start frontend:
   npm run dev

   ✅ Frontend URL: http://localhost:5174

 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Backend won't start:
   • Check Python version: python --version (need 3.10+)
   • Reinstall deps: pip install -r backend/requirements.txt
   • Check GROQ_API_KEY in backend/.env

❌ Frontend won't start:
   • Check Node version: node --version (need 18+)
   • Reinstall deps: cd frontend && npm install
   • Check VITE_API_BASE_URL in frontend/.env

❌ Port already in use:
   • Find process: netstat -ano | findstr :8000 (Windows)
   • Kill process: taskkill /PID <PID> /F
   • Or use different port in configuration

❌ "Cannot reach backend" in frontend:
   • Verify backend is running: curl http://localhost:8000/health
   • Check frontend .env has VITE_API_BASE_URL=http://localhost:8000
   • Restart frontend server: npm run dev
